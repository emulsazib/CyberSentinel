# worth doing on a CUDA host and is a bad idea on CPU (PyTorch has no fast CPU
# kernel for fp16/bf16: measured 0.15 tok/s versus 16.3 tok/s for the GGUF).
#
# For serving a GGUF you do NOT need any of this. Docker skips it unless you
# build with --build-arg INSTALL_TORCH=true.
#
# Install torch from the wheel index matching your hardware FIRST, so pip does
# not pull the default CUDA build onto a CPU-only host:
#
#   CPU:   pip install --index-url https://download.pytorch.org/whl/cpu torch==2.13.0
#   CUDA:  pip install --index-url https://download.pytorch.org/whl/cu129 torch==2.13.0
#   macOS: pip install torch==2.13.0
#
# then: pip install -r requirements-fallback.txt
