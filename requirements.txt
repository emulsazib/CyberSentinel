# CyberSentinel inference runtime.
#
# This is all you need to serve a quantised GGUF policy — the recommended and
# default path. A 4B Q4_K_M model needs ~2.5GB; the same policy unquantised
# through transformers needs ~8GB and has no fast CPU kernel.
#
#   Linux / Docker:   pip install -r requirements.txt
#   macOS (Metal):    CMAKE_ARGS="-DGGML_METAL=on" pip install -r requirements.txt
#
# Use an arm64 Python on Apple Silicon — an x86 build under Rosetta is ~10x slower.
# There are no current prebuilt linux wheels, so this compiles llama.cpp from
# source and needs cmake + a C++ toolchain (the Dockerfile does this in a builder
# stage so the runtime image stays lean).

llama-cpp-python>=0.3.2
